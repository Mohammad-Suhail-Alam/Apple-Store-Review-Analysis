Project Summary
This project analyzes Apple Store product reviews using Python. It applies key statistical concepts to extract insights from user ratings, purchase behavior, and review engagement.

Analysis Performed
Descriptive Statistics:

Calculated mean, median, and mode of app ratings
Analyzed range and interquartile range (IQR) of purchase amounts
Computed variance and standard deviation for the number of likes
Inferential Statistics:

Determined correlation between likes and ratings
Performed a hypothesis test to compare Instagram and WhatsApp ratings
Applied the Central Limit Theorem using random sampling
Visualizations:

Histogram of app ratings to analyze distribution
Sampling distribution to demonstrate the Central Limit Theorem
Dataset
The dataset contains Apple Store product reviews with attributes such as:

App Name
Rating
Purchase Amount
Number of Likes
